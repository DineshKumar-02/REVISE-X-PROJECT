# User Notebooks & PDF Storage

Upload your handwritten and digital PDF study notes here or into `frontend/public/notebooks/`.

### Recommended File Naming:
1. **HTML & CSS**: `html-css-notes.pdf`
2. **JavaScript**: `javascript-notes.pdf`
3. **React**: `react-notes.pdf`
4. **MongoDB**: `mongodb-notes.pdf`
5. **AWS Services (IAM, S3, EC2)**: `aws-services-notes.pdf`
6. **All-in-One Tech Bundle**: `all-in-one-tech-bundle.pdf`

> Tip: Files placed in `frontend/public/notebooks/` can be downloaded directly by students in their browser using `/notebooks/[filename].pdf`.
